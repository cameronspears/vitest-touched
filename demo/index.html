Things to notice

  1. Change money.ts and every test that imports it runs, even the ones that only reach it through other files.
  2. styles.test.ts runs every time. It reads styles.css from disk instead of importing it, so the import graph can't see what it depends on.
  3. Change package.json or vitest.config.ts and every test runs.
  4. Change README.md and nothing extra runs. No test imports it, and it isn't a file every test depends on.
  5. Clear everything and only the test that reads the disk is left.
